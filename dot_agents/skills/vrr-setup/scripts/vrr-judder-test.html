What you are looking for
Lock the content to a rate below your panel's refresh (e.g. 70 or 100 on a 144 Hz monitor). The scrolling rows should drift smoothly and continuously.
A/B test — set your monitor's description (from hyprctl monitors all):
Then edit ~/.config/hypr/monitors.lua so the rule reads vrr = 0, and run hyprctl reload. Repeat at vrr = 1.


  

    Do not use hyprctl eval to toggle vrr — on Hyprland 0.56 a rule
    change where only vrr differs is silently skipped. Edit the file and reload.
  


  

    With VRR off the rows judder in bands as the content rate beats
    against the fixed panel. That difference is your FreeSync working.
